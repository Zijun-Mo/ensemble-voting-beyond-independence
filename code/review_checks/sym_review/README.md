# 对 [S31]（对称参数下任意 K 的闭式）的审查脚本（第二十三份审查）

均以 `python3 -I` 运行，每次运行 < 5 分钟。

- `check_s31.py ident`：三条消元恒等式与系数和公式的 sympy 符号验证（一般 s、t），以及随机化闭式分母公式。结果：残差全为 0。
- `check_s31.py remark`：K=6、(q,b)=(5/18,1/18) 处各规则的精确最坏错误率：独裁 5/18，3 人与 5 人多数 1/6，(2,1,1,1,1,1) 为 4/27，等于精确 R*_det。
- `check_s31.py full K`：消元后的项族与未消元的完整证书族在 8,241 个有理网格点上逐点相等（K=3–12、14 已跑）。
- `check_s31.py rand K`：随机化闭式与精确 LP（全部 2^K 个模式）在 400 个点（含下边界与近边界点）上一致，K=3–10 最大误差 5e-15。
- `check_s31.py det K [秒]`：独立枚举 U_det 的全部胞腔顶点，并用独立编写的 MILP（只加权重排序这一对称破缺）计算 R*_det：K=3–10 的全部非平凡顶点（1/3/2/5/2/6 个，K=5–10）与随机点都一致，最大误差 1e-13。K=10 约 270 秒。
- `irred.py`：U_det 的不可约项数：K=5–10 为 3、5、4、8、5、11；K=11 为 7，K=12 为 14，K=13 为 8，K=14 为 17，K=16 为 20，K=17 为 11。
- `boundary_and_k11.py boundary`：K=5–8 各 99 个边界点上 R*_det = U_det（最大误差 1e-14）。
- `boundary_and_k11.py k11`：K=11 的 6 个内部顶点，用 [S31] 自带的对称破缺 MILP（`sources/S31_bundle/`），全部与 U_det 一致（约 150 秒）。
- `sym_explore.py K 点数 秒`：审查前的探索实验（"最优规则是否总是子委员会规则"），K=3–8 无反例。

注意：所有 MILP 都是浮点求解，属于数值核验；要升级为"计算机辅助（精确）"，需要给每个顶点补有理数下界证书（见选题文档任务 2）。
