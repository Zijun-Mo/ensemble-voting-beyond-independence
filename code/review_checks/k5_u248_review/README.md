# 对 [S26]（异质 K=5 在 R 内的 248 项闭式 U248）的审查脚本（每次运行 < 5 分钟）
所有脚本的第一个参数是 [S26] 验证脚本所在目录（`../../../sources/S26_bundle`），从中导入 248 个证书；均以 `python3 -I` 运行。
- [S26] 脚本原样复跑：快速模式 1 s（248 个证书逐点合法、U188 两个有理反例、12 个轨道的严格暴露见证全部通过）；`--full-bfs` 45 s，335 份 Farkas 证书通过。
- `orbit_census.py`：用 `d2_98_review/rule_vertices.json`（60 类带符号阈值规则的对偶多面体，cddlib 精确枚举，17,508 个顶点）做 S5 轨道普查：1,660 个轨道，其中 12 个即 U248 的 12 个轨道，其余 1,648 个写入 `non_u248_orbits.json`。

- `layers.py`：[S26] §4 饱和层不可约项数 248 / 186 / 181 / 170 / 158 全部复现（浮点 LP）。
